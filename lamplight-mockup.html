Space
Nothing below 15px type, nothing below 44px to tap. The current build's 10–11px labels and button clusters are the clutter.
One action
One primary action per screen in tool mode. Everything else keeps a visible home: pane chips, the ⋯ sheet, Settings cards, or its own screen — nothing is deleted.
Chrome hides
Book mode shows only text — tap to reveal top bar, stats bar, and menu. Moon+ scroll: the chapter flows into the next one as you keep scrolling.

This is a static direction mockup, not the app. All six screens are covered: workspace with ⋯ sheet, reader (Moon+ scroll mode with chapter flow, TTS follow-along, slim bottom stats line), settings, full-screen glossary editor, web importer (scrape-images toggle = scraping-time setting, separate from EPUB export), and EPUB studio (split/merge). The reader menu only contains features we actually have — Visual Options, Themes, TTS, Glossary. Decided: TTS follows along like Moon+; delete list approved minus the scraper images toggle, which becomes its own dedicated setting.
